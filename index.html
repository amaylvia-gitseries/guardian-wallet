The problem

Agents are useful with money and dangerous with it.

People want AI agents that pay for things. Today the choices are all or nothing.

Agents get tricked

One poisoned memo or web page can talk an agent into sending everything it can reach.

App-level checks aren't enough

If the safety rules live next to the agent, whatever fools the agent can fool the rules too.

Keys are all or nothing

You either hand over your whole wallet or approve every single payment by hand.

How it works

The agent proposes. The program decides.

Guardian moves the safety rules out of the app and into a Solana program, where the agent can't argue with them.

01

You set the rules

A daily limit, a list of allowed recipients and a kill switch, stored in an account only you can change.

02

The agent proposes

It asks in plain English. Guardian explains the payment and checks it against your rules before anything is sent.

03

The program decides

The agent's key can only call one instruction. The program rejects anything outside your rules, every time.

Three rules, enforced on-chain

Simple rules you can explain in one breath.

Each one is checked by the program on every agent payment. If a rule fails, the transaction fails and no money moves.

  • Allowlist. The agent can only pay addresses you approved.
  • Daily limit. A rolling 24-hour cap on what the agent can spend.
  • Kill switch. Pause the agent instantly. You can always withdraw.
